## The line

> That spot was not missed. My lidar classified it as a sleeping sock, and I do not vacuum my coworkers.

102 characters — one deadpan excuse from a robot vacuum that takes its sensor readings, and its colleagues, very seriously.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only) writes the line to `/output/entry.txt`. It runs with no network and writes the same bytes every time.
